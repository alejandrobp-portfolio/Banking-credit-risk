# 🏦 Banking Credit Risk Analytics

### SQL · PostgreSQL · Python · Pandas · Power BI

Proyecto de análisis de datos orientado a estudiar el **riesgo crediticio y las características de los clientes asociados a préstamos**.

El análisis utiliza un dataset de aproximadamente **32.000 registros** con información sobre ingresos, historial crediticio, características del préstamo, tasas de interés y antecedentes de default.

## 🎯 Objetivo

Analizar qué características de los clientes y de los préstamos están asociadas con un mayor riesgo crediticio, utilizando distintas herramientas a lo largo de un pipeline de análisis de datos.

## 🛠️ Tecnologías

- **PostgreSQL / SQL** — consulta, transformación y análisis de datos
- **Python / Pandas** — limpieza y análisis exploratorio
- **Power BI** — KPIs, visualización y dashboard
- **Git / GitHub** — documentación y control de versiones

## 🔄 Pipeline

**Raw Data → PostgreSQL → SQL → Python/Pandas → Power BI → Business Insights**

## 📊 Dataset

El dataset contiene variables relacionadas con:

- Edad e ingresos
- Situación de vivienda
- Antigüedad laboral
- Monto y finalidad del préstamo
- Tasa de interés
- Grado crediticio
- Historial de crédito
- Antecedentes de default
- Estado del préstamo
